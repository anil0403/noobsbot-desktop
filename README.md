# Noobsbot Desktop

A macOS-style desktop environment for Linux with a glassy theme, written in Rust on Wayland (Smithay), for a fresh
Arch Linux system. Version 1 codename: **Opal**.

Status: **planning** — see [`plan.md`](plan.md) for the full design. No code yet.

Sister project: [noobsbot-terminal](https://github.com/anil0403/noobsbot-terminal).
